# Repos

공개 git 레포 링크 정리. 주소 + 뭐하는 건지 한줄평만 있어도 충분.

## 목록

| 레포 | 뭐하는 거 | 태그 | 상태 |
|------|-----------|------|------|
| _(예시)_ [anthropics/claude-code](https://github.com/anthropics/claude-code) | Claude Code CLI | #claude #cli | 씀 |

## 새 레포 추가할 때

가볍게 쓸 거면 위 표에 한 줄만 추가.
자세히 남길 거면 `레포이름.md` 만들어서:

```markdown
# owner/repo

> 링크: https://github.com/owner/repo
> 태그: #...
> 상태: 볼거 / 써봄 / 참고용

## 뭐하는 레포
## 왜 저장했나 / 어디에 쓸까
## 메모
```
