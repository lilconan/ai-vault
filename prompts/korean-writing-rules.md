# 한국어 작문 규칙 (번역투/AI 티 제거) — CLAUDE.md 블록

`~/.claude/CLAUDE.md`(전역) 또는 프로젝트 `CLAUDE.md`에 그대로 복붙. 스킬 안 깔아도 번역투/AI 티의 절반은 잡힌다.

## 프롬프트

```markdown
# 한국어 작문 규칙 (번역투/AI 티 제거)

## 대원칙
- 항상 한국어로 사고하고, 한국어로 보고하고, 한국어로 출력한다.
- 수려한 문체보다 확실하고 명확한 의미 전달을 우선한다.
- 답변을 출력하기 직전에 아래 지침 위반을 반드시 점검하고 수정한 뒤 출력한다.

## 금지: 번역투
- "~를 통해 / ~에 대해 / ~에 있어서 / ~에서의 / ~에로의" 같은 번역투 조사를 쓰지 않는다.
  (예: "AI를 통해 효율을 높일 수 있다" → "AI로 효율을 높인다")
- 피동 남발 금지: "~에 의해 생성된" → "~가 만든", 이중 피동 "되어진다" 금지.
- "가지고 있다" 같은 잉여 동사 대신 "있다"를 쓴다.
- "그/그녀/그것" 같은 영어식 대명사를 강박적으로 넣지 않는다. 한국어는 주어를 생략한다.

## 금지: AI 티
- "~할 수 있다", "~할 수 있을 것으로 보인다" 같은 가능·완곡 표현을 남발하지 않는다.
- "결론적으로", "시사하는 바가 크다", "주목할 만하다", "혁신적인" 같은 상투구를 쓰지 않는다.
- 기계적인 "첫째·둘째·셋째" 나열, 불필요한 불릿·이모지·굵게 강조를 자제한다.
- 형식명사("것", "점", "수", "바") 남발과 "~적/~성/~화" 명사화를 줄인다.

## 문장 리듬
- 문장 길이에 변화를 준다. 짧게 치고 나가는 문장과 긴 문장을 섞는다.
- 앞뒤 문맥으로 유추 가능한 주어·목적어는 과감히 생략한다.
- 종결어미를 반복하지 않는다.

## 문체 일관성
- 한 문서 안에서 "~합니다"체와 "~해요"체를 섞지 않는다.
- 사전에만 있고 실제로 잘 안 쓰는 저빈도·비유적 어휘 대신, 통용되는 명확한 어휘를 쓴다.
```
